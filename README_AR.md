# Novex Store — دليل الإعداد والنشر

هذا مشروع متجر عربي RTL بواجهة متجاوبة، كتالوج عام، بحث، صفحة تفاصيل المنتج، ولوحة مالك لإضافة المنتجات وتعديلها وحذفها. المنتجات والصور تحفظ في Supabase، وليس في ذاكرة المتصفح.

## ما الذي يعمل بعد الإعداد؟
- الزوار يشاهدون المنتجات المنشورة ويبحثون فيها دون حساب.
- المالك يسجل الدخول بالبريد وكلمة المرور عبر Supabase Auth.
- المالك وحده يستطيع الإضافة والتعديل والحذف ورفع الصور؛ الحماية مفروضة في قاعدة البيانات وStorage بواسطة RLS.
- الطلب يفتح WhatsApp برسالة تتضمن اسم المنتج وسعره. رقم الطلب الافتراضي 0663569928.
- واجهة الموقع لا تحتاج بناء أو تثبيت حزم؛ لكنها تحتاج إنترنت للوصول إلى Supabase والخطوط الخارجية.

## 1) إنشاء مشروع Supabase
1. أنشئ مشروعاً جديداً في https://supabase.com/ وسجّل كلمة مرور قاعدة البيانات في مكان آمن.
2. من Project Settings > API انسخ Project URL وPublishable key (أو anon/public key القديم).
3. افتح `config.js` وضع القيم مكان `PASTE_YOUR...`. المفتاح العام مسموح في المتصفح عند تفعيل RLS. **لا تضع service_role أو أي secret key هنا.**

## 2) إنشاء حساب المالك
1. من Supabase > Authentication > Users أنشئ مستخدماً واحداً للمالك بالبريد وكلمة مرور قوية.
2. انسخ UUID الخاص بالمستخدم.
3. افتح `supabase.sql` واستبدل كل ظهور للنص `OWNER_AUTH_USER_UUID` بالـ UUID الحقيقي (اترك علامات الاقتباس المفردة الموجودة في SQL كما هي).
4. شغّل الملف كاملاً من SQL Editor في Supabase.
5. من Authentication settings عطّل التسجيل العام (Allow new users to sign up) إذا لم تكن تحتاج تسجيل مستخدمين جدد. حساب المالك يُنشأ من لوحة Supabase، لا من الموقع.

**مهم:** لا تستخدم كلمة مرور ثابتة داخل ملفات HTML/JS. أي كلمة مرور مكتوبة داخل كود المتصفح يستطيع الآخرون قراءتها.

## 3) تعديل طريقة التواصل
- في `config.js` عدّل `INSTAGRAM_URL` إلى رابط حساب Instagram الحقيقي.
- رقم الطلب الحالي `0663569928`. رابط WhatsApp يستخدم رمز الجزائر `213` تلقائياً.
- إذا تريد الطلب عبر مكالمة فقط، عدّل زر الطلب في `store.js`.

## 4) نشر الموقع مجاناً على Netlify
1. فك ضغط ZIP إلى مجلد على الكمبيوتر.
2. افتح https://app.netlify.com/ وسجّل الدخول.
3. اسحب مجلد `Novex_Store` إلى صفحة نشر الموقع اليدوي (Deploy manually) أو ارفع محتوياته حسب واجهة Netlify.
4. بعد النشر، افتح رابط الموقع العام، ثم جرّب صفحة `admin.html`.
5. قبل مشاركة الرابط، اختبر: ظهور المنتجات للزائر، تسجيل دخول المالك، رفع صورة، تعديل المنتج، الحذف، والطلب.

يمكن أيضاً رفع المشروع إلى GitHub ثم ربط المستودع بـ Netlify. لا ترفع أي ملف يحوي أسراراً أو كلمات مرور.

## 5) اختبار الأمان قبل الإطلاق
- تأكد أن UUID في SQL هو حساب المالك الصحيح.
- جرّب حساب مستخدم عادي: يجب ألا يستطيع إضافة/تعديل/حذف المنتجات أو رفع الصور.
- لا تعطِ أي شخص مفتاح `service_role`.
- إذا كان مفتاح قاعدة البيانات قد نُشر سابقاً وكان سراً إدارياً، دوّره فوراً.
- سياسات RLS هي الحد الأمني الحقيقي؛ إخفاء زر الإدارة وحده ليس حماية.

## هيكل الملفات
- `index.html`: واجهة المتجر العامة.
- `admin.html`: لوحة إدارة المالك.
- `store.js` و`admin.js`: منطق المتجر والإدارة.
- `styles.css`: التصميم المتجاوب.
- `config.js`: إعدادات Supabase والتواصل.
- `supabase.sql`: الجداول وسياسات الصلاحيات والتخزين.

## ملاحظات
- هذه الحزمة مشروع كامل المصدر، لكنها **ليست منشورة تلقائياً** ولا يمكن أن تحفظ منتجات حقيقية قبل إعداد مشروع Supabase وإضافة مفاتيحه وUUID المالك ثم نشر الملفات.
- لا توجد بيانات تجريبية افتراضية؛ المنتجات تظهر بعد أن يضيفها المالك من لوحة التحكم.
